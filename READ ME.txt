General - статическая библиотека, содержащая класс для вычисления интеграла, класс для формирования сообщения с результатом, позиции аргументов запуска и несколько математических функций
Lab1 - последовательные вычисления
Lab2 - вычисления с OpenMP
Lab3 - вычисления с MPI
Lab4 - вычисления с OpenCL
RectangleIntegralCs - вычисления на C# с использованием потоков стандартной библиотеки
CppStandThreads - вычисления на C++ с использованием потоков стандартной библиотеки

Исходные данные для вычислений задаются через аргументы командной строки.

Для сборки Lab3 необходимо в свойствах проекта добавить путь к заголовочным файлам MPI SDK.
Для сборки Lab4 необходимо в свойствах проекта добавить путь к заголовочным файлам OpenCL SDK.

В Lab2, Lab4, CppStandThreads, RectangleIntegralCs по умолчанию создаётся 2 потока, далее количество потоков заданное количество раз (аргумент 6) умножается на 2.
Для каждого количества потоков вычисления выполняются заданное количество раз (аргумент 5).

Аргументы запуска:
1 - левая граница интегрирования
2 - правая граница интегрирования
3 - количество прямоугольников
4 - номер функции для интегрирования (от 1 до 5, при других значениях 1)
5 - количество вычислений
6 - количество увеличений числа потоков (Для Lab3 не имеет смысла)
